Changed the single source-of-truth constant `ID_NAMESPACE_DIR` in `engine/src/idMap.ts` from `"n"` to `"notes"`, so a note with id X now publishes at `/notes/X` (e.g. `https://www.glassthought.com/notes/nmfpvvpg1eq081o06s1g18x`). Because all paths (URLs, wikilinks, backlinks, graph, search, canvas embeds) derive from `IdMap.stagedPathOf`, this one change is fully consistent. Exported the constant for DRY reuse in tests. Updated ~11 test files, 8 e2e scripts, and current-tense doc/prose references. typecheck + 592 unit + 87 integration tests pass. BREAKING: old `/n/<id>` URLs 404 after redeploy — no redirects added (not requested). e2e (browser) not run in this env.
